# 本地聊天与办公入口

用户于 2026-11-14 批准：保留并完善聊天，以单 Agent 完成普通办公，增加本地网页入口。
首包为“文本资料→周报→反馈修订→Word 下载→重开继续”。精确契约、限制、权限与实现顺序
唯一维护在 [office-web.md](office-web.md)；本页是中文使用导航，不另维护交付状态。

安装源码可选依赖后运行：

```bash
python -m pip install '.[office]'
pocketchat web --config ./pocketchat.json --data-dir ~/.pocketchat/office
```

打开终端打印的私有链接。链接片段含本次服务令牌，不要转发；服务重启后旧令牌失效。
普通聊天直接输入；需要报告时点击 Create report。Add material 只接受 TXT/Markdown/CSV，
每份最多 12 KiB，一次最多八份、合计 48 KiB；当前模型上下文上限可能要求更少资料。
上传只复制到本地；发送前确认框明确披露会话、当前选择和相关历史将传给所显示模型端点。

完成后可预览、下载 Markdown/Word，或选择某一版本继续修订。旧版本不覆盖。停止操作先显示
Stopping，只有运行线程真正退出才释放工作槽；重启发现未完运行会显示 unknown，不自动再请求。
重试之前回看错误和已有成果；网络回执未知不意味着原请求未执行。

这是同一用户的本地入口，不是公网服务器或同账号恶意进程的沙箱。没有自由 shell、复杂代码
执行、多 Agent、定时任务、PDF/DOCX 输入、OCR、Excel/PPT 输出或账号云同步。
真实模型事实质量、Word 分页和跨平台体验要分别验证，离线桩不能代替。
